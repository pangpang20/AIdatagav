# 非功能需求与验收口径

## 编号与目标来源

按`模块-NFR-序号`建立独立质量要求，关联原功能ID，不重排既有功能或验收ID。每项都写指标/不变量、适用环境、验证方法、失败判定和执行状态。

| 编号 | 质量属性 | 需求与量化指标/不变量 | 验收方法及通过条件 | 关联功能 | 状态 |
|---|---|---|---|---|---|

数值优先使用用户要求、已批准SLA/容量规划或经核对配置；没有依据时可制定合理的开发目标，但在核查记录说明是本次目标、尚无实测及需评审的取舍。没有数据时不虚构当前吞吐、并发、可用率或成本。正文仍直接写目标要求，不插“拟定需求”等标签。

## 质量属性清单

按功能选取，不机械固定13项；与业务无关的条目说明原因。

| 属性 | 必须明确的内容 | 典型验证 |
|---|---|---|
| 传输与秘密保护 | TLS、混合内容、公钥/加密来源与失败、请求/日志/存储的秘密边界；RSA或Base64不替代TLS | 隔离请求判定、配置/代码检查，不保存秘密值 |
| 凭据存储与生命周期 | 密码哈希、盐和参数来源、清理时机、浏览器存储、令牌与密码区分 | 测试标记、受控日志与后端设计检查 |
| 权限与会话 | 服务端验权、隔离、过期/撤销、账号/租户切换、Cookie属性适用性 | 授权隔离角色的直接路径和对象访问 |
| 抗滥用 | 服务端限流维度/窗口/阈值/恢复、账号保护及统一错误信息 | 发布策略的边界与恢复，不能对生产试错 |
| 页面性能 | 首屏到可操作的起止点、冷/热缓存、交互反馈、慢依赖 | 指定浏览器/网络与足量样本的时延分布 |
| 接口与容量 | 端到端起止、并发模型、吞吐、错误率、有效数据规模/查询复杂度 | 真实隔离环境，记录实际资源与安全配置 |
| 可靠性与恢复 | 有限超时、覆盖顺序、重试/取消、结果未知、重复请求、迟到响应/并发 | 故障注入，核对请求数、草稿、锁与数据结果 |
| 可用性与恢复目标 | 观测窗口、探测范围/频率、分母与维护/漏测、必要RTO/RPO | 连续监测或恢复演练；短测不证明月度SLA |
| 审计与可观测性 | 事件字段、请求关联、时间、授权/留存、秘密过滤 | 串联一次成功与失败，不假设某头已被记录 |
| 兼容性与适配 | 平台/浏览器具体版本、视口、缩放、长文本/空状态/弹窗 | 场景与分辨率矩阵，不能只拍默认页面 |
| 可访问性 | 标签/错误关联、键盘/焦点、辅助技术播报、对比度、验证码等替代方式 | 自动扫描加人工键盘/读屏；局部通过不称全面符合 |
| 可维护性与契约 | 统一配置、依赖/版本、接口和错误兼容、可重复生成、环境切换 | 单元/契约/生成器测试与配置矩阵 |
| 资源与长时稳定性 | 页面销毁、监听/定时器、objectURL、上传临时文件、取消/重入 | 重复开关/重入及资源核对，不只看一次成功 |

批处理还应按实际范围处理数据一致性、检查点、幂等、背压、RTO/RPO；查询需明确数据量、索引条件、分页/截断、行列权限；文件需明确大小、类型、存储归属和清理；AI需明确首字/整体延迟、超时/取消、并发、token/成本预算、授权数据、可追溯性和质量评价集。不能照搬登录的认证时延。

## 性能口径

给定指标时一起写：

- 环境：构建、客户端CPU/内存/系统/浏览器、下载/上传带宽与RTT、缓存状态、服务端实例/资源/数据库/网关、业务数据规模、限流与安全策略。
- 负载：并发虚拟用户与在途请求、账号/会话隔离、是否有思考时间、实际吞吐、预热/统计时间、最少样本、真实或模拟依赖。并发数不等于QPS。
- 时延：同一时钟的起止点、包含/排除阶段；说明成功样本与失败样本，不用背景出现或DOM完成代替可操作。
- 算法：样本升序第`ceil(p×N)`项等明确方法；给P50/P95/P99/最大值、样本量与失败次数。零样本、样本不足或环境缺失不判通过。
- 失败：预期业务失败单列；合法请求的5xx、超时、解析错误、错误业务结果和被限流等不得悄悄移出失败率。不得关闭密码校验/安全策略压出好成绩。

压测及持续探测有外部影响，只在用户明确授权范围执行。没有授权就交付可执行验收计划并保持未执行，不能为了完善文档对生产发压测或部署定时任务。

## 可用性、超时与恢复

响应目标、请求超时、会话有效期和恢复目标分别定义。代码兜底不等于实际生效值，数值0可能表示无限超时，必须沿配置/拦截器核对。接口超时不证明服务端未处理；对有副作用的操作先查结果，再决定重试。

可用率明确分母、日历窗口、时隙和探测组成。采用“成功时隙÷应探测时隙”时，失败、无效、漏测不计成功；监测覆盖缺口另报，禁止挑选有效样本夸大可用率。是否包含计划维护必须明确，不能用一次成功或短时压测证明月度达标。

## 非功能验收记录

实际记录环境、指标版本、时间、样本、命令/操作、实测值、通过/失败、证据和限制。未执行写“未执行”；测试未授权、没有后端材料或没有连续监测时说明阻断。文档编号检查、静态源码、自动扫描和单元测试只能支持其覆盖结论。
