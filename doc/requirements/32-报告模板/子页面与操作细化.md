## 3. 编号功能需求

### RTMS-500 报告模板管理 → 报告模板 → · 模板管理

**业务目的**：使用者在“报告模板管理 → 报告模板 → · 模板管理”处理对应对象；与其他菜单分别保留查询条件、对象标识和处理状态。

【页面观察】实际路径为`/rtms/report/reportTemplate/list`。当前页面标题：模板管理。

**用户操作与系统响应**：

1. 从“报告模板管理 → 报告模板 → · 模板管理”进入目标页，先核对当前部门、空间及对象范围。
2. 页面提供的输入或选择提示为：请输入模板名称、请选择报告类型、请选择状态、请选择。其匹配方式、默认值和多条件组合语义待确认。
3. 列表展示：序号、模板名称、部门名称、适用对象、模板说明、报告类型、状态、被引用数、创建时间、操作。记录条数、名称和当时状态属于样本。
4. 可见操作包括：新增。只有本文件另列并附目标页证据的操作才算已进入；其余仅确认入口可见。

【拟定需求】业务依赖：对象唯一范围、引用关系、生命周期状态、读写权限及生效条件需逐项确认；不能从当前记录样本推定全量规则。

**来源与验证**：[V-RTMS-001](../evidence/live-recheck-20261022/V-RTMS-001.png) / [页面元素](../evidence/live-recheck-20261022/V-RTMS-001.json)。仅验证已记载的页面打开和元素读取；接口、持久化、权限隔离和最终业务结果未验证。

## 5. 主要流程

### 模板基本资料、质量方案与绑定步骤分开

【页面观察】新增首步有模板名称200、适用对象200、报告类型、模板文件和模板说明250，结尾下一步。编辑样本的模板名称和报告类型禁用，额外显示质量检测方案与使用默认方案/使用系统方案。页面声明仅docx、不得超过10MB，并提醒不要粘贴图片；未上传或进入后续绑定步骤。

【拟定需求】拟定模板按报告类型与方案版本确定可绑定字段；首步资料、模板文档、字段映射和正式发布分别保存草稿版本。编辑既有模板时说明哪些身份字段不可变、更换文档对映射的影响；取消/返回保留规则需逐步确认。

【待确认】不同报告类型的分支、默认/系统方案的绑定、占位符语法、下一步设计器、图片限制原因、文件大小计量、引用保护与报告生成均待确认。

来源：[V-RTMS-001-op1](../evidence/live-recheck-20261022/V-RTMS-001-op1.png) / [页面元素](../evidence/live-recheck-20261022/V-RTMS-001-op1.json)；[V-RTMS-001-op2](../evidence/live-recheck-20261022/V-RTMS-001-op2.png) / [页面元素](../evidence/live-recheck-20261022/V-RTMS-001-op2.json)。

业务主线：维护报告模板，区分模板文件、设计和报告生成。

跨模块关联仅在页面显示引用时建立；接口和状态契约待评审。

【拟定需求】查询→识别对象→打开目标→核对关联与当前版本→编辑草稿→人工确认→提交→回读结果。正式写入、审批或运行必须有独立授权和服务端结果；本次只执行其中的页面读取部分。

## 7. 待确认与限制

- P0：各对象的读写权限、唯一性范围、状态转换、引用保护、并发和保存结果契约。
- P0：第2节未取得可用正文的目标；维护页后续标签、步骤、类型分支及无可用记录的详情。
- P1：查询匹配与默认条件、空值和排序、分页恢复、动态候选关联、导入失败和取消策略。
- 删除：本轮不自动点击可能直接删除数据的入口；已有确认框证据保留于主文档，未取得确认页的对象继续待核实。
- 任务：可以打开配置，不执行生成、测试连接、发布、调度、重跑、启停或服务调用。
- 开发边界：可实现有依据的界面结构和标明模拟状态的原型；生产写入、接口、算法与完整状态机仍需产品及技术确认。
