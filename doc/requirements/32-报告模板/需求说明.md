修订日期：2026-10-28。本文保留既有需求及验收编号，按页面证据明确字段和交互，并将质量目标与应用验收状态分开。

## 1. 业务目标与使用角色

维护可复用报告模板，供数据标准检测、数据质量检测、安全检测或评价等报告流程引用。

- 业务入口：数据评价 → 报告模板管理 → 报告模板 → 模板管理。
- 使用角色：模板查询、维护和删除的具体角色及部门/空间范围尚无权限矩阵；实现必须遵循服务端授权，不根据菜单可见性推定权限。
- 需求状态：产品、研发和测试评审基线。页面材料来自2026-10-22历史样本，不表示当前线上状态或服务端能力已经验收。

## 3. 功能需求

### RTMS-100 查询报告模板

**业务目的**：按名称、报告类型和状态定位当前会话获准查看的报告模板，并提供可追溯的列表结果。

**开发处理细则**：客户端只提交已批准的筛选、分页和排序字段；服务端按会话及对象范围过滤，成功后以同一响应原子更新结果和总数。没有取得接口契约前不得自行决定参数名、枚举值或成功码。

**操作与规则**：

1. 进入列表后读取筛选候选和当前授权范围内的模板结果。
2. 设置名称、报告类型或状态条件并查询；条件变化后按批准规则从第一页读取。
3. 展示返回的列、状态、引用数和分页信息；重置按批准规则清除条件并重新读取。

**结果与异常处理**：无匹配显示空结果；加载失败、权限拒绝和超时分别显示错误并保留条件。较早请求的迟到响应不得覆盖最新条件；查询只读，不产生业务写入。

#### 4. 接口与数据规则（RTMS-100）

列表与候选读取的方法与相对路径、筛选/分页/排序字段、枚举、响应数据与总数字段由RTMS查询合同交付。页面路由不是API地址；没有真实合同不得编造成功码、默认页大小或请求结构。

HTTP成功与业务成功分别判断；会话过期停止写入，不自动重放保存/删除。身份、对象及关联范围使用服务端合同，普通日志不记录秘密。

### RTMS-102 新增报告模板

**业务目的**：收集报告模板基础资料，为后续设计、绑定和报告生成流程建立可回读的模板对象。

**开发处理细则**：客户端和服务端共同校验必填项、长度、类型和文件策略；服务端重新鉴权并按稳定操作标识处理重复提交。下一步、草稿和最终保存契约未取得前，不得把页面跳转或提示当作创建成功。

**操作与规则**：

1. 打开新增状态，填写模板名称、适用对象、报告类型、模板文件和模板说明。
2. 按批准的字段、类型和文件规则校验，通过后进入后续配置步骤。
3. 完成所有已定义步骤后提交并重新读取创建对象；取消不应创建持久化记录。

**结果与异常处理**：校验失败定位字段并保留可安全保留的输入；文件不合规、无权、超时或服务失败不得显示成功。写入结果未知时先回查再决定重试，临时文件按文件服务策略处理。

### RTMS-103 修改报告模板

**业务目的**：在对象状态和授权允许的范围内修改报告模板资料，并保持版本和引用关系一致。

**开发处理细则**：服务端按对象版本和字段权限重新校验更新请求，不能依赖浏览器禁用控件保护字段。成功后回读对象；并发冲突、超时和失败必须返回可恢复结果。

**操作与规则**：

1. 读取模板及其版本，按对象状态展示可编辑和禁用字段。
2. 修改获准字段并执行名称、长度、关联对象和文件规则校验。
3. 提交更新后回读同一对象；取消、返回或失败按批准的草稿和临时文件策略处理。

**结果与异常处理**：未授权字段、过期版本、关联失效和服务异常不得改变原对象；明确失败保留非敏感输入，结果未知先回查，不覆盖较新版本。

2. 新增时填写首步资料并选择报告类型；在文件规则和后续设计器定义后进入配置步骤，最终保存并回读同一模板。现有证据止于首步。
3. 编辑时加载目标模板及版本，按对象状态展示可编辑字段；服务端保存允许字段，成功后回读。
4. 删除时打开确认层；取消不变更对象，确认后由服务端按权限、引用及状态规则处理。删除结果未验证。
5. 复制、发布、取消发布、报告生成和详情查看只有可见入口或没有独立目标证据，不属于本版已定义流程。

本仓库未发现RTMS前端调用端或后端契约实现，故不写未经证实的HTTP方法、API路径、参数、业务码、DTO或状态机。RTMS前后端负责人补齐接口合同后，方可进行持久化功能开发和服务端验收。
