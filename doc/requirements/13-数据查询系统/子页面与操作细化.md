#### 3. 业务流程与异常分支（DQ-500）

1. 会话及范围校验后分别加载用户候选和列表，行以id识别。
2. 筛选→查询→datas/total；成功空结果与失败分开；重置/翻页独立管理当前条件。
3. 标签先建副本草稿，校验后人工确定；删除确认所选ID后提交。
4. logId查看结果按1/2/3轮询；重执行确认覆盖后以id受理取得queryId；去修改只导航。
5. 成功回读；关闭/离页/失权清理轮询及受限数据；超时先核查，不自动重复执行。

**结果与异常处理**：空结果、无权、会话失效、业务拒绝、超时、网络与解析错误分开。校验失败定位输入，来源失效阻止执行。保存/删除/执行结果未知先核查；离页只停止本地等待，不承诺服务端回滚。

#### 3. 业务流程与异常分支（DQ-501）

1. 进入加载来源和最近历史；route query回填来源/SQL时格式化，不自动执行；选源读表。
2. 元数据→查看列/生成草稿/追加表名；编辑/格式化/全屏/本地下载不发送执行请求。
3. 人工执行校验权限、只读语句与配额，POST两字段快照返回queryId后轮询。
4. 1继续五秒轮询，2按header/headerCn/body渲染，3显示msg；空body成功不判失败，畸形字段不伪造空结果。
5. 当前执行与草稿匹配方可保存；历史只复制，清除历史单独确认回读。
6. 断网、未知状态、离页停止本地轮询；数据库可能继续，按queryId核对，禁止自动重放。

## 4. 字段与业务规则

### 公共请求与响应契约

父应用getRequestInstance提供会话客户端，MODULE_URL_PREFIX.mdm覆盖默认/mdm/portal，commonUser覆盖/common/user；路径按默认网关/back列出。普通POST为application/json对象或ID数组，GET标识置path；undefined可能序列化省略，不把省略/null/空字符串混同。列表pageNo=1、pageSize=20、order=[{prop:"id",asc:false}]来自公共mixin；用户候选20条、表清单50条为独立分页。

withCredentials及会话头按父配置，仅登记名称adq-token、条件X-CSRF-TOKEN、X-TIMESTAMP/X-NONCE/X-SIGN不记值。普通正常链解包response.data；HTTP 202业务错误reject，无code=0默认协议。1002认证失效、1003无权限、1109转改密、1012刷新按父应用处理；局部错误finally解锁，恢复不重放SQL。导出rawData/blob保留原响应交文件工具。

超时路径非负配置优先，再取请求number timeout，缺省回退20000ms；0未排除，不能保证现网20秒结束。目标要求有限期限与恢复；HTTP等待、SQL执行时限、会话有效期分开定义，实际值由服务端/部署合同交付。

### 身份、结果和草稿

行id用于标签/删除/reExec，logId及新queryId用于result；dataSourceId为来源，不以名称/序号替代。SQL执行body只有dataSourceId、sql；无schema独立选择及SQL参数表单，schemaName来自表元数据。生成select按列顺序及schema/table构成草稿，不代表方言、只读、权限验证完成。

header/headerCn按索引映射，body行数组；显示列仅视图操作，不构成字段授权。重复mixName不得覆盖列，合法null/0/false及精度、空中文名、空结果/错误分别测。已查无结果分页/取消API，不编造URL或“已终止数据库任务”。标签10字符/5条；目标新增trim后非空/唯一性/副本编辑，差异见核查记录。

日期yyyy-MM-ddTHH:mm:ss无时区后缀，服务端时区/端点包含性、标签匹配和限额必须合同交付，不由AI自选。optModuleList常量存在但页面无模块筛选，optModule按返回文本展示。

| 执行受理 | query/reExec标识 | 仅受理；按标识GET result核查 |
| 运行/成功/失败 | status=1/2/3及header/headerCn/body/msg | 1等5000ms；2含空行成功；3显示安全msg；失败不自动重执行 |
| HTTP/业务失败 | 202/全局错误、5xx/超时/网络/解析异常 | 区分无权/拒绝/故障，保留安全草稿并解锁 |
| 写结果未知 | 无明确业务终态/回读 | 先核查已生效范围，不臆断幂等/事务回滚 |
| 导出 | rawData Blob | 校验媒体类型、错误消息、文件名/范围，失败留条件并释放objectURL |

## 5. 主要业务流程

入口/来源授权→读取表或个人记录→本地筛选/编辑→人工执行取得queryId→明确终态→保存当前执行引用→logId查看结果；审计独立记录/查询。本地下载、保存引用、受理、成功、清历史和删个人记录分别验收。
