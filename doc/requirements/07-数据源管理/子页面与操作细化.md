#### 3. 业务流程与异常分支（DS-500）

**操作与规则**：

1. 进入页面，在当前身份/范围内读取/back/common/datasource/driver/page；响应按datas/total或数组映射到列表。
2. 输入条件→查询→第1页；返回列表时恢复本路由已提交条件/页码，重入和切账号不得串用旧数据。
3. 按稳定标识进入详情或授权动作；只读查询不会自动测试连接、初始化、上传或远端发现。

**结果与异常处理**：

| 分支 | 页面结果、数据影响与恢复 |
|---|---|
| 读取中/合法空结果 | 读取中保留当前条件与忙碌反馈；成功空结果展示空态，不据此认定查询故障。 |
| HTTP202/5xx/断网/响应结构错误 | 错误态与空态分开，保留条件并允许原条件重试；页码越界按有效页回读，不静默显示为无记录。 |
| 查看/条件动作无权限 | 服务端核对象和动作；失权时清内容，直接URL或对象ID也不能绕过。只读查询不自动执行行级动作。 |
| 快速查询/翻页/离页后响应迟到 | 按本次条件和对象隔离响应；旧结果不覆盖新查询，离页清理加载状态与监听。 |
| 表单维护分支 | 本页筛选不创建或修改定义，不适用新增表单必填、保存加密或临时文件回滚；行级维护及外部测试转对应功能规则。 |

#### 3. 业务流程与异常分支（DS-508）

#### 3. 业务流程与异常分支（DS-511）

**操作与规则**：

1. 进入新增模型dataSourceId为空且清单[]，读取来源候选；所属ID不能从API记录或Topic序号推定。
2. 选择来源→手动拆分名称或人工获取远端候选→去重加入草稿；获取失败与成功空清单分开。
3. 逐Topic配置主体、mysql数据库类型、Key/Value枚举；增加字段，校验名称正则及唯一、字段类型、长度，模态确认写回正确全局行。
4. 主表再次检查所有Topic及字段→人工保存完整模型→成功后回原列表及配置详情核清单。草稿行删除、配置删除、远端Topic删除是不同动作。

| 分支 | 页面结果、数据影响与恢复 |
|---|---|
| 候选/详情/模板失败 | 区分失败对象与合法空态；局部重试保留有效且有权的草稿。依赖失败不放宽来源、部门或字段校验，不虚构默认。 |
| 必填/长度/格式/枚举/引用失效 | 阻止提交，定位字段及所在页签；服务端拒绝映射到可理解错误，保留有效输入。不自行生成额外必填。 |

#### 3. 业务流程与异常分支（DS-512）

## 5. 主要流程

3. 按需人工测试草稿或既有连接；逐驱动结果独立于定义保存状态，失败可修正，不能因进入页面自动外连。
4. 已有连接按可见范围进入可用列表；有权用户在API中定义四组参数，在Kafka中手动或人工获取Topic并配置字段，分别保存元数据。
5. 编辑保持稳定ID及锁定来源/驱动集合；删除、启停和初始化分别授权，保护引用，失败保留、未知结果先核。返回列表回读同范围资料，不由成功文案推断远端数据变化。
