# 数据源管理子页面与操作需求细化

## 1. 范围与入口

业务目标：管理数据接入定义、驱动和部门可用范围，供后续任务选择数据源。本文件补充[模块需求正文](./需求说明.md)，按真实菜单层级分开说明对象、维护页面和前置条件。

页面字段和操作结果来自当前账号的只读取证。功能建议与页面事实分开；业务保存、删除、审批、授权及任务执行均未验收。

### DS-500 数据源管理 → 数据源管理 → · 驱动管理

**业务目的**：使用者在“数据源管理 → 数据源管理 → · 驱动管理”处理对应对象；与其他菜单分别保留查询条件、对象标识和处理状态。

【页面观察】实际路径为`/datasource/dataSource/driveList`。

**用户操作与系统响应**：

1. 从“数据源管理 → 数据源管理 → · 驱动管理”进入目标页，先核对当前部门、空间及对象范围。
2. 页面提供的输入或选择提示为：请输入驱动名称、请选择是否初始化数据、请选择。其匹配方式、默认值和多条件组合语义待确认。

## 5. 主要流程

业务主线：管理数据接入定义、驱动和部门可用范围，供后续任务选择数据源。

接入定义和实际连通性分别判断；驱动、数据源类型与动态参数的组合规则需确认。凭据字段不得用于普通列表输出。

【拟定需求】查询→识别对象→打开目标→核对关联与当前版本→编辑草稿→人工确认→提交→回读结果。正式写入、审批或运行必须有独立授权和服务端结果；本次只执行其中的页面读取部分。

## 7. 待确认与限制

- P0：各对象的读写权限、唯一性范围、状态转换、引用保护、并发和保存结果契约。
- P0：第2节未取得可用正文的目标；维护页后续标签、步骤、类型分支及无可用记录的详情。
- P1：查询匹配与默认条件、空值和排序、分页恢复、动态候选关联、导入失败和取消策略。
- 删除：本轮不自动点击可能直接删除数据的入口；已有确认框证据保留于主文档，未取得确认页的对象继续待核实。
- 任务：可以打开配置，不执行生成、测试连接、发布、调度、重跑、启停或服务调用。
- 开发边界：可实现有依据的界面结构和标明模拟状态的原型；生产写入、接口、算法与完整状态机仍需产品及技术确认。
