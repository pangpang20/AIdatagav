# 运维监控子页面与操作需求细化
<!-- 业务规格格式:plain-v1 -->

## 1. 范围与入口

业务目标：查看监控对象、告警和恢复信息，区分状态读取和运维动作。本文件补充[模块需求正文](./需求说明.md)，按真实菜单层级分开说明对象、维护页面和前置条件。

本细化覆盖总览、三类对象管理与监控、告警规则、通知设置和告警事件页面。页面呈现、配置保存、目标连接、监控采集、告警触发及通知送达属于不同结果，不得相互替代。

## 2. 功能范围

| 页面/需求 | 本规格涵盖 |
|---|---|
| 总览（OMMS-500） | 查看三类对象数量、状态概况、最近轮询时间和资源指标。 |
| 服务器、应用服务器、数据库对象（OMMS-501至OMMS-503） | 查询对象列表并打开相应新增表单（OMMS-510至OMMS-512）。 |
| 服务器、应用服务器、数据库监控（OMMS-504至OMMS-506） | 查询并查看页面提供的监控状态和对象字段。 |
| 告警规则（OMMS-507） | 查询规则列表；新增和修改规则（OMMS-513、OMMS-514）。 |
| 通知设置（OMMS-508） | 查询设置并新增通知接收配置（OMMS-515）。 |
| 告警事件（OMMS-509） | 按页面条件查询和查看告警记录。 |

本规格没有定义独立详情、对象编辑/删除、人工启停监控或告警确认/清除流程。若产品需要这些操作，须先提供业务流程、状态影响和授权规则，再另行细化。
