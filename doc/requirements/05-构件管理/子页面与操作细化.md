#### 2. 页面交互规则（CMS-500）

| 控件/触发方式 | 行为、联动、禁用与反馈 |
|---|---|
| 搜索/清空/Enter | 搜索按钮与Enter统一发keyword查询，清空后重新读取；新筛选回第一页。关键字作为文本安全高亮，不使用innerHTML。 |

| 收起/展开/标签更多 | 箭头只改变筛选区域高度；结果标签更多展开剩余全部标签，不丢中间项；条件与已提交结果保持对应。 |
| 全选/单选 | 选择范围为当前已加载页，使用稳定id、支持半选；文案明确“本页”，不能声称全选全部匹配记录。查询/翻页时清理不属于当前页的选择并更新数量。 |

#### 3. 业务流程与异常分支（CMS-500）

**操作与规则**：

1. 读取分类、数据库/类型和业务候选，候选就绪后按当前条件请求超市列表。
2. 搜索/选择筛选或分页，提交实际页码及候选id；用请求代次接收datas/total。
3. 查看目标或按本页id选择下载范围；打开下载弹窗后读取有效候选并校验选择。
4. 确认才请求下载；校验原始响应及blob，交浏览器保存文件；计数/个人记录/批次结果按服务器契约回读。
5. 取消/X/Escape清理未提交选择；失败可恢复条件，已发导出结果未知时先核查，不能自动重复生成。

**结果与异常处理**：

| 异常分支 | 结果、数据影响及恢复 |
|---|---|
| 无权限/会话过期/对象失效 | 终止读写并清除无权内容，提示重新登录或返回；不能将失权当成功空数据。 |
| 依赖/接口读取失败 | 说明失败对象，解除忙碌并保留可恢复输入；重新加载依赖不覆盖用户当前草稿。 |
| 网络超时/202业务拒绝/5xx | 区分业务错误和技术失败；读可按原条件重试，有副作用请求结果未知先回读，不能自动重放GET或POST。 |
| 重复/状态或引用冲突 | 使用服务端真实字段及错误契约定位；同目标在途锁防重入，批量结果逐项核对，不虚构全局名称唯一或批量原子性。 |

#### 3. 业务流程与异常分支（CMS-505）

**操作与规则**：

1. 加载记录并区分空态与失败；请求包装器当前没有筛选/分页参数。
2. 按真实后端契约决定启用筛选与分页；未交付时明确不可用，不展示虚假筛选结果。
3. 点击当前批次查看，带batchId进入个人列表；该范围作为固定条件继续查询/分页/重置。
4. 返回记录页面恢复上下文；本页不生成、修改或删除导出记录。

**结果与异常处理**：

| 异常分支 | 结果、数据影响及恢复 |
|---|---|
| 无权限/会话过期/对象失效 | 终止读写并清除无权内容，提示重新登录或返回；不能将失权当成功空数据。 |
| 依赖/接口读取失败 | 说明失败对象，解除忙碌并保留可恢复输入；重新加载依赖不覆盖用户当前草稿。 |

### AI辅助规则开发与检索

提供三个独立扩展场景：根据用户选定的授权需求与标准生成规则草稿及{变量}说明；对当前规则给出静态风险、数据库适配和缺失条件建议；在超市检索中根据需求推荐可复用候选及匹配依据。输入只含当前明确选择的资料和获授权候选；输出逐条给引用、适用数据库、假设及不确定项。用户逐项采纳可撤销地写入当前草稿或筛选条件，不自动创建名称、上传jar、保存、发布、运行规则或下载。模型不可用/超时保留原人工流程。来源授权、正确性、延迟、取消和成本评测按CMS-NFR-014及独立接入契约实施。

## 5. 主要业务流程

1. 维护业务分类和名称基础资料，开发时选择或输入名称，核对已有规则组合。
2. 按分类、类型和数据库对象编辑多个规则草稿，必要时上传算法包；保存留页，确认保存后返回。
3. 在开发列表单项/批量发布或撤销发布，未发布状态可编辑/删除；供给范围以服务端发布及授权契约为准。
4. 在超市按关键词、分类、数据库、业务及时间检索，查看只读详情，按本页选择单项或批量下载。
5. 在个人构件中查询、查看、下载或移除个人记录；从导出记录查看通过batchId限定个人列表。下载、个人记录与导出批次的产生/更新时点按服务端契约核对。

## 7. 实现与交付边界

已明确字段、调用端模型、相对路径和目标交互可支持页面及已知调用端开发。真实持久化仍须取得后端授权矩阵、请求/响应DTO、发布和批量事务、文件与导出、个人移除范围、记录筛选/分页等[外部交付契约](./核查记录.md#外部依赖)。不得由AI猜测成功码、生成编码、状态机或未定义接口。

历史操作编号的适用性与具体边界见[主文档第7节](./需求说明.md#7-实现与交付边界)。

AI辅助规则草拟、静态审查与候选推荐属于独立规划，采纳仅更新可撤销草稿，不自动执行规则或业务写入，见[AI详细规则](./子页面与操作细化.md#ai辅助规则开发与检索)。
