# 构件管理业务需求说明

本轮逐链接进入的目标、表单与字段补充见[子页面与操作细化](./子页面与操作细化.md)；未取得目标的操作仍列待确认。

## 1. 业务目标与使用角色

维护可复用的数据规则构件及其分类、名称和个人使用清单。

- 使用角色：构件开发人员、构件使用人员（角色名称待确认）。
- 业务入口：需求管理 → 构件管理。
- 文档状态：基于现有界面的需求草案，供产品、研发和测试评审；角色权限、后端规则和待确认项尚未定稿。

## 2. 业务范围

本模块涉及下列对象。已有界面可以支持定义的功能在第3节展开；尚缺业务规则的操作在第7节逐项登记。

| 业务对象 | 本版可展开的功能 | 尚需定义 |
|---|---|---|
| 构件开发 | 查询与列表、详情、新增 | 编辑、删除确认 |
| 构件名称配置 | 查询与列表、新增、编辑、删除确认 | 详情 |
| 我的构件 | 查询与列表、详情 | 新增、编辑、删除确认 |
| 构件分类 | 目标业务页面待补充 | 查询与列表、详情、新增、编辑、删除确认 |
| 导出记录 | 目标业务页面待补充 | 查询与列表、详情、新增、编辑、删除确认 |

## 3. 功能需求

本节用“用户操作—系统响应—业务规则”描述需求。已有界面支持的字段和入口按现有范围整理；带【拟定需求】的行为需产品确认。所有业务验收用例在本轮均未执行。

### CMS-100 查询构件开发

**业务目的**：帮助用户查找构件开发，并核对与后续处理有关的信息。

**操作与规则**：

1. 用户进入构件开发页面。
2. 用户可按构件名称、构件ID设置条件，查询所需记录。
3. 结果展示序号、构件ID、构件名称、业务类型、构件分类、数据库对象、发布状态、创建人、创建时间，供用户识别对象和核对信息。

**结果与异常处理【拟定需求】**：查询无匹配记录时展示空结果；查询失败时保留条件并允许重试。重置后的默认条件、分页与排序由产品确认。

字段规则见第4节；需求依据见第8节的 CMS-100。

**开发处理细则【拟定需求】**：

- 输入：构件名称、构件ID。每个条件的匹配方式与默认值按下述对象规则和公共交互约定执行。
- 响应：查询开始保留条件并显示加载；成功原子替换结果与总数；空结果显示“暂无数据”；失败保留条件、显示错误和重试入口。
- 竞态与恢复：短时间连续查询只展示最后一次条件对应的响应；改变条件从第一页查询；从详情返回恢复已提交条件及页码。
- 数据影响：只读取当前授权范围的数据，不因查看列表改变对象状态；查询条件不等于导出授权。

这些细则是待产品评审的实现建议；页面事实及本对象特有依赖以第4、7、8节为准。

### CMS-101 查看构件开发

1. 用户选择目标构件开发并打开查看页面。
2. 系统展示对象的基础信息及页面已有的规则、关联或配置内容，供用户核对。
3. 用户返回原业务入口；返回时需要保留哪些查询条件见公共交互要求。

- 输入：所选构件开发标识与当前空间；响应为当前授权可见的基础字段和已定义关联项，不以列表缓存代替最新详情。

### AI开发审查结论

- 可先实现：本模块已列出的入口、展示结构、明确字段长度、当前禁用状态，以及公共规则中的加载/空/失败/取消界面；使用模拟数据实现时明确标示。
- 业务写入与执行：尚未达到生产开发就绪。四种规则编辑器、保存/确认/发布语义、分类/导出页及个人移除的真实范围是必须明确的业务输入，不允许AI自行选择一套并当成已确认规则。
- 拟定需求的使用：可据此制作交互原型和评审稿；正式持久化、权限、接口和外部任务行为需评审规则及接口协议后再实现。
- 本模块全部查询/详情/新增/修改/删除的逐对象范围保留于本节登记；未知操作不视为产品确定支持。

| 检查项 | 本版结论 |
|---|---|
| 字段与输入边界 | 已观察维护操作4项；明确部分字段及子配置。 |
| 状态与权限 | 当前样本不是完整状态机；角色/空间/部门权限待业务定义。 |
| 成功及异常 | 本文处理细则与公共规则已提出可测试建议，尚未验证应用写入。 |
| 数据模型与接口 | 本文给逻辑对象和输入输出语义，未规定物理表或虚构现网API。开发协议须单独评审。 |
| 验收 | 每条用例均拟定未执行；字段边界、取消/重试、权限、重复及恢复已按适用操作展开。 |
