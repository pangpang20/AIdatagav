<!-- 业务规格格式:plain-v1 -->

本文件补充[评价管理业务需求](./需求说明.md)，逐页定义EMS-500–512的页面字段、操作、异常流程、安全、布局和验收。所有流程描述的是目标业务行为；页面观察与缺口依据见[核查记录](./核查记录.md)。

## 1. 范围与入口

评价管理入口位于数据评价菜单下，覆盖方案管理、主观/客观指标、任务管理、执行管理、填报审核、申诉审核、评价报告及我的评价。页面字段/路由来自仓库保存的2026-10-22历史页面与DOM材料，不能代表当前部署的最新状态。

## 3. 编号功能需求

### EMS-500 方案管理

**业务目的**：按方案名称或编号、状态检索方案，并查看方案标识及关联信息。

实际路径为`/ems/programmeManage/list`。当前页面标题：方案管理。

**用户操作与系统响应**：

1. 从“方案管理”进入目标页，先核对当前部门、空间及对象范围。
2. 页面提供的输入或选择提示为：请输入方案名称或编号、请选择状态。匹配方式、默认条件和组合语义由批准的查询契约定义。
3. 列表展示：序号、方案编号、方案名称、应用描述、所属部门、关联指标、关联任务、关联模板、创建时间、状态、操作。记录条数、名称和当时状态属于样本。
4. 详情、编辑和删除按独立需求及服务端权限合同定义，不从“操作”列推断行为。

列表当前样本显示“暂无数据”；空列表只代表该次读取未展示记录，查询失败由独立错误状态呈现。

方案、指标与任务的唯一性、引用保护、生命周期和授权规则由领域模型与服务端契约统一约束。

**来源**：[V-EMS-001](../evidence/live-recheck-20261022/V-EMS-001.png) / [页面元素](../evidence/live-recheck-20261022/V-EMS-001.json)。接口、持久化、权限隔离及业务结果的证据边界见[核查记录](./核查记录.md#核查结论)。

#### 2. 页面交互规则（EMS-500）

| 控件/按钮 | 交互行为与状态 |
|---|---|
| 查询 | 按当前筛选条件发起只读检索；加载中显示状态，失败时保留筛选条件并提供重试。 |
| 重置 | 清空当前筛选并恢复初始条件；是否自动查询按页面统一交互规则实现。 |
| 筛选字段 | 只更新当前查询条件，不触发写入；受控候选读取失败须独立显示并允许重试。 |
| 页面离开 | 不自动提交；离开列表不改变数据，返回时按批准导航规则恢复已提交条件。 |

#### 3. 业务流程与异常分支（EMS-500）

1. 进入方案管理，确认会话有效并由服务端按授权范围读取列表；仅在打开具体方案时使用其稳定对象标识。加载失败显示独立错误并提供重试。

2. 按已观察字段设置筛选条件；匹配方式、默认排序和状态枚举必须使用批准的业务字典与查询契约。
3. 查询成功展示结果及分页；空结果与加载失败、无权限、服务异常分别呈现。
4. 网络超时、服务端校验失败、权限不足和响应异常须明确提示并保留筛选条件；不得把空结果判为故障。
5. 分页、重复查询和条件变更不得串用旧响应；较早请求的迟到结果不能覆盖较新的筛选状态。

| 异常分支 | 目标页面响应 |
|---|---|
| 空结果/无权限 | 明确区分无匹配数据与无权访问，不显示为系统错误。 |
| 网络或服务异常 | 展示失败状态并保留筛选、分页上下文供重试。 |
| 网络超时/服务端错误 | 显示读取失败且不伪装为空列表；保留筛选条件并允许安全重试只读查询。 |
| 查询重试/迟到响应 | 重试只执行只读查询；较旧响应不得覆盖新筛选条件对应的结果。 |

#### 6. 权限与安全要求（EMS-500）

- 允许访问本页面及执行该操作的角色、部门、租户和数据范围；菜单可见不等于写权限。
- 服务端对查询条件、对象标识、租户/空间和读取权限重新鉴权，拒绝越权参数；不能仅依赖前端隐藏按钮。
- 全链路使用批准的传输保护；评价内容、附件和会话秘密不写入普通日志、截图说明或错误消息；日志只保留必要的操作审计字段。
- 写入、导出与审核必须分别鉴权并记录必要审计；会话过期后拒绝写入并清理敏感草稿。

#### 7. 页面布局与状态（EMS-500）

- 页面路由：/ems/programmeManage/list；截图：[V-EMS-001](../evidence/live-recheck-20261022/V-EMS-001.png) / [页面元素](../evidence/live-recheck-20261022/V-EMS-001.json)。
- 按本项字段表排列控件；动态名称、数量、日期和状态仅为历史样本值，不作为固定业务规则。
- 加载中禁用会导致重复请求的控件并显示进度；空状态保留筛选入口和对象上下文；错误状态说明原因并提供重试；成功状态显示服务端返回结果。
- 在1366×768、1920×1080及200%缩放下保持标题、筛选和主要操作可见；长文本可换行或滚动，弹窗不得遮挡取消/确认。
