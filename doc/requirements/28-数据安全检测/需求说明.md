## 1. 业务目标与使用角色

组织待识别库表，维护数据分类、分级和识别规则，配置安全检测方案与任务，并对识别/检测结论进行授权复核。使用角色必须以产品批准的角色—动作—对象范围矩阵为准；页面样本显示登录用户和租户标签，但不能据此推定固定角色、租户参数或写权限。入口为数据评价 → 数据安全检测。

## 5. 主要业务流程

取得授权和目标对象 → 查询库表待办 → 选择数据源与库表 → 维护分类/分级和识别规则 → 形成检测方案版本 → 创建检测任务并选择数据源/方案/调度 → 服务端受理并可查询运行状态 → 查看检测结果 → 有权限人员复核 → 正式等级/结论及审计回读。导航菜单不证明这些步骤已端到端连通；当前多个目标页与路由不一致，须先补证。
