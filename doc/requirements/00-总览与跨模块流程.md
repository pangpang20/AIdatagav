# 总览与跨模块流程

## 产品范围、用户与信息架构

【页面观察】用户指定应用名“数据中台”；登录与工作台显示“数据运营平台”。版本未知。实际展开需求管理、数据开发、数据一体化、数据资产、数据评价、后台六组导航；加上登录/工作台公共模块，整理35个模块。来源：[工作台](./evidence/E004-portal-ready.png)、[需求导航](./evidence/E005-demand-nav.png)、[开发导航](./evidence/E021-development-nav.png)、[一体化导航](./evidence/E037-unification-nav.png)、[资产导航](./evidence/E043-assets-nav.png)、[评价导航](./evidence/E052-evaluation-nav.png)、[后台导航](./evidence/E059-backend-nav.png)。

【页面观察】当前会话显示空间、租户、消息与当前用户。只使用一个获授权账号，未切换空间/租户。业务、开发、治理、审批、运维等是根据页面任务提出的【拟定需求】使用角色，不是已验证权限矩阵。

| 分组 | 实际模块 |
|---|---|
| 公共 | 登录、工作台 |
| 需求管理 | 业务需求管理系统、数据需求管理、构件管理、我的工单 |
| 数据开发 | 数据源管理、数据集成采集、任务编排与调度、规范化数据建模、数据标准管理、数据直报、数据查询系统 |
| 数据一体化 | 目录管理系统、数据共享交换、数据服务支撑、数据服务门户、数据服务门户后台管理 |
| 数据资产 | 元数据管理、指标管理、标签管理、智能查询系统、资产目录系统、数据安全保护、数据表管理、运营汇总系统 |
| 数据评价 | 数据标准检测、数据安全检测、数据质量检测、评价管理、AI数据智能辅助、报告模板 |
| 后台 | 工作空间、运维监控、微服务平台 |

## 逐对象CRUD范围

35个模块共登记115个对象/功能分区：50个已取得目标列表/卡片，65个仅有父页或导航线索。分别取得3个详情、27个新增、12个编辑以及10个删除确认；另1个删除入口请求被拦截、未见确认。上述数量不能当作完整CRUD完成率。738条需求、1383条验收条目包含明确待确认及拟定未执行内容。

详见[覆盖矩阵](./增删改查覆盖矩阵.md)与[逐操作索引](./逐操作需求索引.md)。只读打开页面不验证服务端、持久化、权限、算法、审计和业务闭环。

## 证据强度与限制

页面/DOM与列明只读步骤有直接证据；服务端、数据完整性、算法、权限、安全与业务闭环证据不足。冲突并列保留，优先使用同页面、同操作和同时刻截图；独立补采只证明补采时刻。页面自身后台活动没有核实触发来源。

业务资料按要求不额外脱敏；页面自己隐藏的星号段没有明文证据，不猜测。分发范围见[README](./README.md)，逐模块覆盖、约束和限制见各模块说明。
