# 智能查询系统业务需求说明

## 1. 业务目标与使用角色

提供即席查询入口，并通过查询范围配置限定可使用的数据。

- 使用角色：即席查询使用者（具体授权范围待确认）。
- 业务入口：数据资产 → 智能查询系统。
- 文档状态：基于现有界面的需求草案，供产品、研发和测试评审；角色权限、后端规则和待确认项尚未定稿。

## 2. 业务范围

本模块涉及下列对象。已有界面可以支持定义的功能在第3节展开；尚缺业务规则的操作在第7节逐项登记。

| 业务对象 | 本版可展开的功能 | 尚需定义 |
|---|---|---|
| 即席查询范围 | 目标业务页面待补充 | 查询与列表、详情、新增、编辑、删除确认 |

## 3. 功能需求

本节用“用户操作—系统响应—业务规则”描述需求。已有界面支持的字段和入口按现有范围整理；带【拟定需求】的行为需产品确认。所有业务验收用例在本轮均未执行。

### IDQS-001 组织即席查询配置

**业务目的**：提供即席查询入口，并通过查询范围配置限定可使用的数据。

**操作与规则**：

1. 页面提供设置查询范围、选择已有配置、保存当前配置、查询和重置入口。

**业务规则与待确认**：配置内容、保存范围、权限继承和查询执行规则待确认。

**结果与异常处理【拟定需求】**：无法访问或加载失败时给出明确提示，保留可恢复的业务上下文。

**开发处理细则【拟定需求】**：

- 输入与范围：采用当前用户、租户、空间和页面明确的时间/分类条件；未定义统计口径的指标只可展示样稿，不实现猜测算法。
- 响应状态：首次加载、刷新、空数据、部分指标失败和失权分别展示；失败指标不填0冒充成功，显示数据时间及重试入口。
- 入口：菜单目标独立验权；只有取得目标页面证据的范围才在本模块定义业务功能。

这些细则是待产品评审的实现建议；页面事实及本对象特有依赖以第4、7、8节为准。

## 4. 字段与业务规则

长度和可修改范围以现有界面为依据；未明确的格式、唯一性、组合约束和服务端规则在第7节确认。样本名称、日期、数量及当前选项不作为固定产品规则。

本模块尚无可展开的维护表单；查询/展示字段和界面说明见[调研记录](./调研记录.md#4-字段枚举和约束)，具体维护字段待确认。

## 5. 主要业务流程

【拟定需求】业务流程草案：设置查询范围 → 组织查询 → 查看结果；范围配置及查询执行规则待确认。各环节之间的自动流转、数据传递和状态联动需产品确认，不能由导航入口推定。

【拟定需求】用户在保存、删除、发布、审批、授权或任务运行前应明确操作对象和影响；成功给出结果，失败保留可恢复信息，取消策略及重复操作规则统一评审。

### AI开发审查结论

- 可先实现：本模块已列出的入口、展示结构、明确字段长度、当前禁用状态，以及公共规则中的加载/空/失败/取消界面；使用模拟数据实现时明确标示。
- 业务写入与执行：尚未达到生产开发就绪。范围配置页、关联表/连接条件、运算符、排序分页、自然语言/SQL边界是必须明确的业务输入，不允许AI自行选择一套并当成已确认规则。
- 拟定需求的使用：可据此制作交互原型和评审稿；正式持久化、权限、接口和外部任务行为需评审规则及接口协议后再实现。
- 本模块全部查询/详情/新增/修改/删除的逐对象范围保留于本节登记；未知操作不视为产品确定支持。

| 检查项 | 本版结论 |
|---|---|
| 字段与输入边界 | 尚无足以定义完整维护行为的目标表单。 |
| 状态与权限 | 当前样本不是完整状态机；角色/空间/部门权限待业务定义。 |
| 成功及异常 | 本文处理细则与公共规则已提出可测试建议，尚未验证应用写入。 |
| 数据模型与接口 | 本文给逻辑对象和输入输出语义，未规定物理表或虚构现网API。开发协议须单独评审。 |
| 验收 | 每条用例均拟定未执行；字段边界、取消/重试、权限、重复及恢复已按适用操作展开。 |
