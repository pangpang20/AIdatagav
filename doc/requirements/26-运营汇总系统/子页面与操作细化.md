#### 3. 业务流程与异常分支（OSS-500）

1. 页面进入 → 服务端确认会话和部门/数据范围 → 获取目录页；页面或字典依赖失败时进入错误态，不以空表代替。
2. 用户设置名称、部门、资源类型及额外条件 → 点击查询 → 请求携带当前筛选和 `pageRequest` → 成功显示字段、分页和总数。
3. 用户重置 → 条件恢复初始值、页号回 1 → 新请求回读；迟到旧响应不覆盖新条件。
4. 用户点名称 → 以稳定 `id` 打开只读详情 → 服务端重新验权并读取；缺失/失权不回显旧列表样本。
5. 网络失败、超时、5xx、字典失败和格式错误显示为可恢复错误；只读查询可由用户重试。超时不代表服务端没有处理，不适用副作用幂等承诺。

#### 3. 业务流程与异常分支（OSS-501）

1. 从菜单进入 `/oss/myCatalogue/applyList` → 服务端按当前用户鉴权 → 查询本人记录。

#### 3. 业务流程与异常分支（OSS-502）

1. 进入页面 → 查询 `getAdqstdTableMapping` → 成功展示映射行，零条显示空态；未初始化提示、接口异常和无权限分别处理。
2. 页面显示“请先初始化”时停止业务读取并提示初始化前置状态；初始化由有权限的独立模块执行。本页面不能自动初始化，也不能把初始化失败伪装为空数据。
3. 用户查询标准表名 → 提交当前条件及分页排序 → 返回 `datas/total` 或经批准的新结构；重置回第一页。
4. 有权限用户改动行内值 → 服务端核验 `trgTabId`、权限、版本及组合规则 → 更新 → 回读行。提交失败恢复原行值；超时核查当前服务端值，不直接双击重试。
5. 读取和字典错误、数据结构异常、会话过期及请求竞态不得覆盖新状态；用户重载不得重复执行任何写入。
