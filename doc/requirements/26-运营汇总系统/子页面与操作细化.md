## 3. 编号功能需求

### OSS-500 运营统计汇总 → 部门目录中心

**业务目的**：使用者在“运营统计汇总 → 部门目录中心”处理对应对象；与其他菜单分别保留查询条件、对象标识和处理状态。

【页面观察】实际路径为`/oss/deptCataCenter/list`。当前页面标题：部门目录中心。

**用户操作与系统响应**：

1. 从“运营统计汇总 → 部门目录中心”进入目标页，先核对当前部门、空间及对象范围。
2. 页面提供的输入或选择提示为：请输入目录名称、请选择数源单位、请选择资源类型、请选择。其匹配方式、默认值和多条件组合语义待确认。
3. 列表展示：序号、目录名称、数源单位、资源类型、安全级别、更新周期、是否级联共享、共享类型、数据范围、供数方式、目录分级。记录条数、名称和当时状态属于样本。
4. 可见操作包括：数据原名_test_api、文件123、文件abc、婚姻信息10、婚姻信息08、婚姻信息07、人员信息婚姻04、人员信息婚姻03、人口信息API、婚姻人员信息、src_cyl、xxmr内部资源目录、a_rkcj、a_tes_ytestk2_rkxx_t1、公积金人口信息、人口流动信息目录、人口信息数据目录、交通管理信息目录、资源A、asfd。只有本文件另列并附目标页证据的操作才算已进入；其余仅确认入口可见。

【拟定需求】业务依赖：对象唯一范围、引用关系、生命周期状态、读写权限及生效条件需逐项确认；不能从当前记录样本推定全量规则。

**来源与验证**：[V-OSS-001](../evidence/live-recheck-20261022/V-OSS-001.png) / [页面元素](../evidence/live-recheck-20261022/V-OSS-001.json)。仅验证已记载的页面打开和元素读取；接口、持久化、权限隔离和最终业务结果未验证。

## 5. 主要流程

### 运营统计与数据开发读取有不同前置

【页面观察】已分别进入部门目录中心、我订阅的目录和数据开发情况。数据开发情况有标准表名、表描述、源表位置、源表名、更新时间、更新频率、启用拉链和表类型列，同时出现请求异常、点击重新加载与请先初始化，当前未执行初始化。

【拟定需求】拟定目录统计、订阅关系与开发表同步使用各自来源和更新时间；单一来源不可用时标明局部失败，不显示为业务零值。初始化应说明影响范围与权限，完成后再只读加载；重试保持筛选上下文并防止迟到响应覆盖。

【待确认】统计分母、跨模块去重键、来源延迟、初始化产生的记录和开发数据真实结果待确认。V-OSS-004实际为内容不存在错误页，未取得监控大屏业务正文，不将其算作大屏功能证据。

来源：[O-OSS-001](../evidence/live-recheck-20261022/O-OSS-001.png) / [页面元素](../evidence/live-recheck-20261022/O-OSS-001.json)；[O-OSS-002](../evidence/live-recheck-20261022/O-OSS-002.png) / [页面元素](../evidence/live-recheck-20261022/O-OSS-002.json)；[O-OSS-003](../evidence/live-recheck-20261022/O-OSS-003.png) / [页面元素](../evidence/live-recheck-20261022/O-OSS-003.json)。

业务主线：汇总目录运营、订阅和开发情况，并核对跨系统指标来源。

跨模块关联仅在页面显示引用时建立；接口和状态契约待评审。

【拟定需求】查询→识别对象→打开目标→核对关联与当前版本→编辑草稿→人工确认→提交→回读结果。正式写入、审批或运行必须有独立授权和服务端结果；本次只执行其中的页面读取部分。

## 7. 待确认与限制

- P0：各对象的读写权限、唯一性范围、状态转换、引用保护、并发和保存结果契约。
- P0：第2节未取得可用正文的目标；维护页后续标签、步骤、类型分支及无可用记录的详情。
- P1：查询匹配与默认条件、空值和排序、分页恢复、动态候选关联、导入失败和取消策略。
- 删除：本轮不自动点击可能直接删除数据的入口；已有确认框证据保留于主文档，未取得确认页的对象继续待核实。
- 任务：可以打开配置，不执行生成、测试连接、发布、调度、重跑、启停或服务调用。
- 开发边界：可实现有依据的界面结构和标明模拟状态的原型；生产写入、接口、算法与完整状态机仍需产品及技术确认。
