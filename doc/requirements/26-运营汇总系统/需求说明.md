### OSS-100 查询部门目录中心

**业务目的**：按授权范围查找部门目录并核对目录信息。

**操作与规则**：

1. 从部门目录中心进入并读取目录、部门树和字典。
2. 设置目录名称、数源单位、资源类型及展开条件，提交查询；重置回第一页。
3. 读取服务端当前页及总数；从目录名称按稳定 ID 进入只读详情。

**结果与异常处理**：读取中、成功有数据、合法空结果、失败及失权分别呈现。失败保留有效条件并允许用户重试；迟到响应不能覆盖新条件。

**开发处理细则**：输入草稿与已提交条件分离，查询原子更新结果和总数；按路由恢复非敏感条件，切换身份清理旧数据；详情按稳定 ID 独立读取与鉴权。读取重试不触发初始化或写入。

## 5. 主要业务流程

1. 用户从数据资产菜单打开目标页；页面在服务端确认权限后读取数据。菜单隐藏和按钮隐藏只作界面约束，不能替代接口鉴权。
2. 用户输入/选择筛选条件并查询；条件与分页参数一起提交。成功结果、合法空结果和异常分别呈现；重置清空筛选并回第一页。
3. 用户从部门目录名称打开只读详情；详情按稳定目录 ID 重新读取。对象不存在或当前身份失权时显示不可访问/不存在状态，不沿用列表样本冒充详情。
4. 数据开发页未初始化或上游读取失败时明确显示前置条件/错误，并提供只读重载。初始化由有权限的独立流程执行，当前页面不得自动初始化。
5. 有编辑权限的用户变更数据开发行内值时，服务端重新鉴权并校验版本；成功后回读该行，失败时恢复服务端值。超时先回读状态，避免重复写入。
