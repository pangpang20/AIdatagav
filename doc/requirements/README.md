## 证据标签

- 【页面观察】：可见文字、控件、选项或客户端属性，不能证明服务端校验。
- 【操作观察】：确实执行的只读操作及当时结果，详细过程放调研附录。
- 【页面文案】：页面声明，不能据此宣布后端实现或测试通过。
- 【拟定需求】：业务设计建议，等待产品确认。
- 【待确认】：缺少规则、目标页面或执行证据。
- 【拟定，未执行】：业务验收计划，不算应用测试通过。
