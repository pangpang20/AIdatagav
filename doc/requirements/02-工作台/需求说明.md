# 工作台业务需求说明

## 1. 业务目标与使用角色

为用户提供应用入口、个人事项和工作场景指引。

- 使用角色：平台使用者。
- 业务入口：公共入口 → 工作台。
- 文档状态：基于现有界面的需求草案，供产品、研发和测试评审；角色权限、后端规则和待确认项尚未定稿。

## 2. 业务范围

本模块涉及下列对象。已有界面可以支持定义的功能在第3节展开；尚缺业务规则的操作在第7节逐项登记。

| 业务对象 | 本版可展开的功能 | 尚需定义 |
|---|---|---|
| 工作台 | 应用导航与个人事项 | 异常、权限和状态恢复规则 |
| 右上角用户菜单（补充） | 已实际打开基本信息、修改密码、主部门弹窗及后台首页和子页；[字段、流程及证据](./用户菜单补充清单.md) | 退出未执行；保存、改密、改部门及服务端权限仍待验证 |

## 3. 功能需求

本节用“用户操作—系统响应—业务规则”描述需求。已有界面支持的字段和入口按现有范围整理；带【拟定需求】的行为需产品确认。所有业务验收用例在本轮均未执行。

### HOME-001 选择应用

**业务目的**：为用户提供应用入口、个人事项和工作场景指引。

**操作与规则**：

1. 工作台提供六组应用导航，用户选择目标应用进入对应业务模块。

**业务规则与待确认**：应用可见范围与角色/空间的关系待确认。

**结果与异常处理【拟定需求】**：无法访问或加载失败时给出明确提示，保留可恢复的业务上下文。

**开发处理细则【拟定需求】**：

- 输入与范围：采用当前用户、租户、空间和页面明确的时间/分类条件；未定义统计口径的指标只可展示样稿，不实现猜测算法。
- 响应状态：首次加载、刷新、空数据、部分指标失败和失权分别展示；失败指标不填0冒充成功，显示数据时间及重试入口。
- 入口：菜单目标独立验权；只有取得目标页面证据的范围才在本模块定义业务功能。

这些细则是待产品评审的实现建议；页面事实及本对象特有依赖以第4、7、8节为准。

#### 3. 业务流程与异常分支（HOME-001）

1. 进入选择应用，读取当前用户、租户/空间和对象标识；页面加载失败时停留在当前页并提供重试。
2. 按字段表填写或选择；缺少必填值、长度越界、格式不合法或确认值不一致时阻止提交并定位字段。
1. 进入选择应用，在当前用户、租户/空间及数据权限范围内加载页面；加载失败时保留页面上下文并可重试。
2. 按已观察字段设置筛选条件；未确认的匹配方式、默认排序和状态枚举不得由实现人员推断。
3. 查询成功展示结果及分页；空结果与加载失败、无权限、服务异常分别呈现。
4. 网络超时、服务端校验失败、权限不足和响应异常须明确提示并保留筛选条件；不得把空结果判为故障。
5. 分页、重复查询和条件变更不得串用旧响应；较早请求的迟到结果不能覆盖较新的筛选状态。

| 异常分支 | 预期页面响应（均为拟定，待产品/服务端确认） |
|---|---|
| 空结果/无权限 | 【拟定需求】明确区分无匹配数据与无权访问，不显示为系统错误。 |
| 网络或服务异常 | 【拟定需求】展示失败状态并保留筛选、分页上下文供重试。 |
| 网络超时/服务端错误 | 【拟定需求】展示可理解的失败状态，保留可安全保留的草稿；结果未知时先查询状态，避免错误重试。 |
| 取消/重复提交 | 【拟定需求】取消不产生未确认写入；重复点击在客户端去重并由服务端幂等保护。 |

- 【待确认】字段默认值、完整长度与格式、逐按钮确认框、提交中禁用策略、错误文案、重试/幂等和状态恢复需逐项补证。
- 【拟定需求】AI 实现前必须将上述待确认项转为调查任务；在证据补齐前只实现已观察的页面结构，并把未知行为显式作为配置或接口契约占位。
## 4. 字段与业务规则

长度和可修改范围以现有界面为依据；未明确的格式、唯一性、组合约束和服务端规则在第7节确认。样本名称、日期、数量及当前选项不作为固定产品规则。

本模块尚无可展开的维护表单；查询/展示字段和界面说明见[调研记录](./调研记录.md#4-字段枚举和约束)，具体维护字段待确认。
