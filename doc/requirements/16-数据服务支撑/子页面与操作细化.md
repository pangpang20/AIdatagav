接口读取失败时保留来源和已合法草稿，失效会话按公共认证流程恢复；主记录、关联与真实下游结果分别回读。

#### 3. 业务流程与异常分支（GSB-506）

1. 读取当前身份、部门及入口权限后初始化列表；读取失败显示错误并允许重试。
2. 编辑筛选草稿，查询/重置/页签/部门切换后发对应只读请求；只有最后一次查询可更新结果与total。
3. 区分加载、合法空、无权、失败和有记录；进入详情保留稳定ID与来源条件，返回恢复当前范围。

接口读取失败时保留来源和已合法草稿，失效会话按公共认证流程恢复；主记录、关联与真实下游结果分别回读。

## 5. 主要业务流程

| GSB-110 | 查询服务审批 | GSB-503的todo/done两个接口；不是服务列表筛applyStatus。 |
| GSB-111 | 查看服务审批 | 任务携服务id/taskId/workflowCode/businessId打开audit；流程只读记录独立。 |
| GSB-112 | 新增服务审批 | 由launchApplication产生流程，不能人工任意新建审批；下一节点及路由由流程合同定义。 |
| GSB-113 | 修改服务审批 | 只允许有权待办通过/驳回，POST task/approve或reject；意见100，不能编辑历史快照。 |
| GSB-114 | 删除服务审批 | 无独立历史删除入口；撤回仅serviceRegister/revoke，留存清理另行合同，不造DELETE task。 |
| GSB-115 | 查询服务控制 | GSB-504申请IP与GSB-505访问策略分别查询，不把计数当策略输入。 |
| GSB-116 | 查看服务控制 | 当前申请IP关系、访问策略及统计快照，configId/applyId分开。 |
| GSB-117 | 新增服务控制 | IP映射新增POST addSystemIpMapping；访问策略独立新建入口未在所查组件出现，不造POST策略。 |
| GSB-118 | 修改服务控制 | IP映射更新沿用POST并携关系id；策略GSB-509 PUT configId，锁/解锁另动作。 |
| GSB-119 | 删除服务控制 | DELETE deleteSysIpMappingById仅删IP关系；无访问历史/策略任意删除入口。 |

### AI开发审查结论

已取得前端字段、联动、路由、事件和API包装器，可据明确范围开发界面及契约测试；生产持久化、签名、审批事务、部署、下游消费及限流安全尚未验收。不能将本次文档细化称为生产就绪。

外部交付包：后端提供OpenAPI与真实成功/错误响应、状态映射/版本并发及唯一域；流程负责人提供申请/审批/撤回/重提的状态与任务归属；服务网关负责人提供签名/凭据/授权、有效期/IP/额度计数合同；部署负责人提供模板变量、缺参拒绝、异步结果/回滚及旧版本兼容；资源/文件负责人提供批次事务、引用保护、文件id/key与留存。逐包缺口、所查范围与受阻验收见核查记录，不用通用DTO占位冒充真实合同。
