### DQTS-500 智能识别管理 → 列分析

**业务目的**：使用者在“智能识别管理 → 列分析”处理对应对象；与其他菜单分别保留查询条件、对象标识和处理状态。

【页面观察】实际路径为`/dqts/columnAnalysis/list`。当前页面标题：列分析。

**用户操作与系统响应**：

1. 从“智能识别管理 → 列分析”进入目标页，先核对当前部门、空间及对象范围。
2. 页面提供的输入或选择提示为：请输入任务名称、请选择数据源名称、请输入表名称。其匹配方式、默认值和多条件组合语义待确认。
3. 列表展示：序号、任务名称、数据源名称、表名称、分析类型、任务状态、创建人、创建时间、分析报告、操作。记录条数、名称和当时状态属于样本。
4. 可见操作包括：新增。只有本文件另列并附目标页证据的操作才算已进入；其余仅确认入口可见。

【页面观察】采样中出现“暂无数据”；它可能属于列表、下拉或子表，须结合截图定位。不能据此宣称整个模块无数据，也不能用空列表证明查询失败。

【拟定需求】业务依赖：规则阈值、分母、空值处理、样本范围和报告有效期需定义；分析结果不能自动升级为正式检测结论。

#### 3. 业务流程与异常分支（DQTS-500）

1. 进入智能识别管理 → 列分析，读取当前用户、租户/空间和对象标识；页面加载失败时停留在当前页并提供重试。
2. 按字段表填写或选择；缺少必填值、长度越界、格式不合法或确认值不一致时阻止提交并定位字段。
1. 进入智能识别管理 → 列分析，在当前用户、租户/空间及数据权限范围内加载页面；加载失败时保留页面上下文并可重试。
2. 按已观察字段设置筛选条件；未确认的匹配方式、默认排序和状态枚举不得由实现人员推断。
3. 查询成功展示结果及分页；空结果与加载失败、无权限、服务异常分别呈现。
4. 网络超时、服务端校验失败、权限不足和响应异常须明确提示并保留筛选条件；不得把空结果判为故障。
5. 分页、重复查询和条件变更不得串用旧响应；较早请求的迟到结果不能覆盖较新的筛选状态。

**业务目的**：使用者在“数据质量检测 → 检测方案”处理对应对象；与其他菜单分别保留查询条件、对象标识和处理状态。

- P0：各对象的读写权限、唯一性范围、状态转换、引用保护、并发和保存结果契约。
- P0：第2节未取得可用正文的目标；维护页后续标签、步骤、类型分支及无可用记录的详情。
- P1：查询匹配与默认条件、空值和排序、分页恢复、动态候选关联、导入失败和取消策略。
- 删除：本轮不自动点击可能直接删除数据的入口；已有确认框证据保留于主文档，未取得确认页的对象继续待核实。
- 任务：可以打开配置，不执行生成、测试连接、发布、调度、重跑、启停或服务调用。
- 开发边界：可实现有依据的界面结构和标明模拟状态的原型；生产写入、接口、算法与完整状态机仍需产品及技术确认。
