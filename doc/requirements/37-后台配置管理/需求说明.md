# 后台配置管理需求说明

## 1. 范围与入口

后台管理→配置管理。维护平台导航所依赖的应用、系统、平台分组、字典、特殊日期和许可证信息；数据源分组还有驱动、数据源、部门数据源、数据源列表、API与Kafka入口，相关业务统一追溯到[数据源管理需求](../07-数据源管理/需求说明.md)，不另建一套连接配置规则。

这里的“系统管理”路径为`/module-common/config/system/list`，与后台“系统管理”导航分组不同。应用、系统、平台三个对象也不得因名称近似合并。

## 3. 编号功能需求

### BCF-001 查询和创建应用

【页面观察】应用列表展示名称、类型、应用场景、最后更新人/时间和操作；存在内部、外部两类样本。新增页`/module-common/config/app/edit`默认内部应用，包含必填类型、名称、应用KEY。名称与KEY上限100。

**业务流程**：查询目标应用→新增→选择类型→填写对应分支→校验→提交。已执行到打开表单，后续为【拟定需求】。KEY在此是应用标识，是否另有认证凭据不由字段名称推断。内部应用和外部应用的初始化、唯一范围、可选系统与接入协议须确认。

【拟定需求】重名/重复KEY应定位字段；创建失败不能留下可点击但不可访问的入口；重复提交不能创建重复应用。取消不写入应用。外部URL仅作为配置数据，不在后台自动请求任意目标。

**来源与验证**：[R064-app-0](../evidence/live-recheck-20261022/R064-app-0.png)。仅页面/控件读取及明确记载的只读动作；业务提交、权限与服务端结果未验收。

#### 3. 业务流程与异常分支（BCF-001）

1. 进入查询和创建应用，读取当前用户、租户/空间和对象标识；页面加载失败时停留在当前页并提供重试。
2. 按字段表填写或选择；缺少必填值、长度越界、格式不合法或确认值不一致时阻止提交并定位字段。
1. 进入查询和创建应用，读取当前用户及租户/空间上下文；页面或候选项加载失败时保留当前页并提供重试。
2. 仅填写页面已观察字段；校验必填、格式、长度和跨字段关系。密码一致性、唯一范围和默认关联均须先查证。
3. 提交前由服务端重新鉴权并验证唯一性；重复账号/对象返回可定位的冲突，不覆盖已有记录。
4. 对账号重复、确认值不一致、字段校验、权限不足、网络超时及服务端错误分别显示状态；非秘密输入可按批准规则保留，秘密值不得回填。
5. 取消不发送创建请求；超时结果不明时先按请求关联号或目标查询确认是否已创建，再决定是否重试。

| 异常分支 | 预期页面响应（均为拟定，待产品/服务端确认） |
|---|---|
| 重复账号/对象 | 【拟定需求】展示服务端冲突字段与提示；不覆盖、不生成第二条记录。 |
| 必填、格式或跨字段校验失败 | 【拟定需求】定位字段并保留可安全重试的数据；真实规则与提示待验证。 |
| 网络超时/服务端错误 | 【拟定需求】展示可理解的失败状态，保留可安全保留的草稿；结果未知时先查询状态，避免错误重试。 |
| 取消/重复提交 | 【拟定需求】取消不产生未确认写入；重复点击在客户端去重并由服务端幂等保护。 |

#### 6. 权限与安全要求（BCF-001）

- 【待确认】允许访问本页面及执行该操作的角色、部门、租户和数据范围；菜单可见不等于写权限。
- 【拟定需求】服务端对对象标识、租户/空间、操作权限、版本和幂等键重新鉴权，拒绝越权参数；不能仅依赖前端隐藏按钮。
- 【拟定需求】全链路使用批准的传输保护；密码、令牌、Cookie和个人数据不写入日志、截图说明或错误消息；日志只保留必要的操作审计字段。
- 【待确认】是否需要二次确认、审批、操作审计、敏感字段脱敏、数据导出限制和会话过期处理。

- P1：日期算法、上传大小/格式、失败重试和并发策略。以上不能由当前输入属性替代服务端定义。
